Como usar o Fiscalis

Guia rápido e respostas para as dúvidas mais comuns.

Primeiros passos

  1. Peça à sua empresa um token válido para consultar a API do IBPT. Sem ele, o serviço não consegue buscar os percentuais.
  2. Digite o token e o CNPJ habilitado para a consulta. O token aparece mascarado e não é guardado pelo Fiscalis; o CNPJ é incluído no histórico.
  3. Informe o NCM do produto, selecione a UF, descreva o produto e informe seu valor em reais. Unidade, GTIN e exceção podem ser preenchidos quando aplicáveis.
  4. Clique em Consultar estimativa e aguarde a resposta. Os percentuais e os valores aproximados aparecem no quadro de resultado.
  5. Role até Histórico recente para conferir consultas anteriores. Use Atualizar se quiser recarregar a lista.
  6. Para consultar uma tabela IBPT que você já baixou, abra Tabela IBPT no menu, escolha o CSV no seu computador e use a busca, os filtros, a ordenação e a paginação. Marque Simular item em uma linha de produto ou serviço, informe o valor de venda e calcule uma estimativa discriminada.

O que significa cada campo?

NCM / código:
classificação fiscal do produto. Confirme o código correto com sua contabilidade.
UF:
estado considerado na consulta.
Descrição e valor:
identificação do produto e preço usado para estimar os valores de tributos.
GTIN:
código de barras, se disponível.
Unidade e exceção:
parâmetros adicionais exigidos pela classificação consultada; use os dados fiscais do produto quando conhecidos.

Perguntas frequentes

O resultado é o valor definitivo do imposto?

Não. É uma estimativa informativa calculada com os percentuais retornados pelo IBPT. A tributação real pode depender de outros dados e regras. Confirme com um profissional contábil.

Por que a consulta pode falhar?

Confira a conexão com a internet, o token e o CNPJ, a UF e o NCM. A API do IBPT ou o banco também podem estar temporariamente indisponíveis. A mensagem exibida indica se é necessário tentar novamente.

O Fiscalis guarda meu token?

Não. O token é enviado ao backend para realizar a consulta, mas não é salvo no banco nem exibido no histórico. O CNPJ, os dados do produto, os percentuais e a data são persistidos no MySQL local.

Onde ficam as consultas anteriores?

Na seção Histórico recente desta página. O banco usa um volume Docker persistente; parar os containers não apaga os dados.

Como consultar por ramo de atividade?

Na tela Tabela IBPT, selecione um ramo estimado pelo capítulo do NCM e, se quiser, combine com a busca de texto. Essa categoria organiza produtos e não determina oficialmente o ramo da sua empresa.

Como consultar a tabela IBPT baixada?

Abra Tabela IBPT no menu e selecione o CSV no seu computador. A tabela é carregada só no navegador, onde você pode pesquisar, filtrar por ramo estimado, ordenar pelas colunas e paginar os resultados.

Como simular o total de um produto ou serviço?

Na tabela IBPT, marque a caixa da coluna Simular item, informe o valor de venda na modal e clique em Calcular estimativa. Para produtos, escolha se deseja o cenário federal nacional ou importado; esses cenários não são somados entre si. A simulação discrimina os valores disponíveis e soma a estimativa ao preço informado. É uma referência informativa, não uma definição de quanto deve ser cobrado.

Como encerro o aplicativo?

No terminal em que o Compose está rodando, pressione Ctrl+C. Para remover os containers, execute docker compose down. Evite docker compose down -v, pois esse comando também apaga o histórico armazenado.

Onde consigo ajuda para instalar?

Consulte o README do projeto no GitHub para ver os requisitos e o passo a passo de instalação.

Proteja suas credenciais e não exponha este MVP publicamente sem revisar sua configuração de segurança.
